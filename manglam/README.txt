This is an example for displaying pictures from a folder.
There are two options:
1. In the directory conatining pictures, create a file manifes.json which will contain list
picture files to dislpaly. Modify this file to which picture file to directory.
2. If manifest.json is missing, all files in directory will be displayed.

How to test:
Change pictures and manifest.json file in pictures/group1 folder
open index.html in browser and check that picures have changed.
